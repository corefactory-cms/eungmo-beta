오늘 한국 시간 기준으로 휴대폰에서 참여할 수 있는 무료 이벤트를 조사해 주세요. 현재 목록은 https://corefactory-cms.github.io/eungmo-beta/events.json 에 있습니다. 주최 측 최신 원문과 실제 신청 화면에서 연도·접수 여부·경품·참여 조건을 확인해 주세요. 마감한 기존 행사도 공식 발표가 있는지 확인해 주세요.

결과는 UTF-8 JSON 파일 하나로 주세요. 최상위는 {"events":[...]}입니다. 코드블록 설명은 파일에 넣지 않습니다. 기존 행사라면 원래 id를 그대로 쓰고 바뀐 필드와 verifiedAt만 보내도 됩니다. 신규 행사의 필드는 아래와 같습니다.

id              영문 소문자·숫자·하이픈으로 구성한 고유 이름
title           행사명
organizer       주최 기관
prize           경품 종류·금액·인원. 미공개면 미공개라고 표시
entryMethod     응모 방식 한 줄
rules           대상·참가 조건, 중복 응모 기준 등 핵심 사항
startDate       시작 날짜 YYYY-MM-DD 또는 null
deadline        확인된 마감 날짜 YYYY-MM-DD
deadlineTime    명시된 한국 시간 HH:MM 또는 null
drawDate        공식 추첨일 또는 null
announcementDate  공식 발표일 또는 null
announcementMethod  공식 안내를 문장으로 작성. '12월 중', '개별 문자'도 그대로 기재
sourceUrl       주최 측 행사 원문 HTTPS 주소
entryUrl        주최 측이 제공한 응모 HTTPS 주소
announcementUrl  발표 게시판 등 추후 확인할 곳의 HTTPS 주소 또는 null
resultUrl       실제 발표를 확인한 해당 행사 결과 게시물 HTTPS 주소 또는 null
claimDeadline   수령 신청 기한 YYYY-MM-DD 또는 null
verifiedAt      원문 확인일 YYYY-MM-DD

개인의 이름·연락처·응모번호·당첨자 명단·쿠폰 번호 등 개인 기록은 담지 마세요. 홈페이지나 발표 예정 장소를 이미 발표된 결과 주소로 적지 마세요.
